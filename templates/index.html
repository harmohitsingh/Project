🎯 Fairness Interpretation

📚 Fairness Metrics Explained

Approval Rate
% of applicants in this group who were approved. Should be similar across groups for equal opportunity.
True Positive Rate (TPR)
% of qualified applicants correctly approved. Measures equal opportunity — divergence means some groups face higher rejection despite being qualified.
False Positive Rate (FPR)
% of unqualified applicants incorrectly approved. Should be consistent — higher FPR for one group may indicate the model is biased in their favor.
Bias Threshold
A difference of more than 10% between groups in any metric is flagged as potential bias requiring investigation.
ℹ️ About This Project
10
United Nations SDG 10 — Reduced Inequalities
"Reduce inequality within and among countries" — by 2030, empower and promote social, economic, and political inclusion of all, irrespective of age, sex, disability, race, ethnicity, origin, religion, or economic status.

🎯 Project Goal

Build an ML-powered loan approval predictor that not only predicts fairly but also audits itself for bias across gender, education, and other sensitive attributes — helping identify and challenge systemic discrimination in financial lending.

📦 Dataset

Realistic Indian Home Loan Dataset — 2,000 applications generated from real-world Indian income distributions (Rs.10K–Rs.5L/month), loan amounts (Rs.5L–Rs.2Cr), and bank approval logic including FOIR, loan-to-income ratio, and credit scoring.

🤖 ML Pipeline

  • Label encoding of categorical features
  • Feature engineering: EMI, LTI ratio, total income
  • StandardScaler normalization
  • 3 models compared: RF, GBT, LR
  • Best selected by AUC-ROC score
  • 5-fold cross-validation

⚖️ Fairness Features

  • Post-prediction bias audit by gender
  • Approval rate parity analysis
  • True positive rate equality check
  • False positive rate monitoring
  • Explainability via key factor breakdown

🛡️ Input Validation

  • All categorical fields validated against allowed values
  • Numeric fields have strict min/max bounds
  • Business rule: EMI cannot exceed 90% of income
  • Live financial preview updates in real time

🔧 Tech Stack

  • Python 3.11 + scikit-learn
  • Flask (REST API backend)
  • Vanilla JS + CSS (no frameworks)
  • Realistic Indian Loan Dataset (2,000 records)
